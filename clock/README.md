# ⏰ Clock & Stopwatch Web App

A sleek and functional web app that shows the current time and includes a stopwatch you can start, stop, and reset—all built with HTML, CSS, and JavaScript.

## 📦 Features
- Digital clock that updates every second
- Stopwatch with millisecond accuracy
- Easy-to-use Start, Stop, Reset buttons
